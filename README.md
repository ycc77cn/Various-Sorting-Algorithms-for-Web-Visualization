# Various-Sorting-Algorithms-for-Web-Visualization
Various Sorting Algorithms for Web Visualization...

- This is an HTML-based project developed with AI. It’s quite interesting, don’t you think?

- It includes common sorting algorithms such as Bubble Sort, Selection Sort and Insertion Sort, high-performance sorts like Quick Sort, Merge Sort and Heap Sort, a variety of non-comparison sorts including Radix Sort, Counting Sort and Bucket Sort. It also features some quirky sorts, such as Bogosort, Sleep Sort, Pancake Sort, Miracle Sort and Thanos Sort. More algorithms may be added in future updates.

- It supports custom bars, color differentiation, and descriptions for each sorting method.


- 这是一个 HTML 做的网页项目，由 AI 辅助开发。里面实现了各式各样的排序算法可视化：
- 有冒泡、选择、插入这类基础排序；快排、归并、堆排序这些高效排序；基数、计数、桶排序等非比较类排序；还有猴子排序、睡眠排序、煎饼排序、奇迹排序、灭霸排序这种脑洞奇葩排序，后续还会继续新增算法。

- 支持自定义柱状条、颜色区分，每个排序算法都附带介绍。整体挺有意思的。
